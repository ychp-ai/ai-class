# 项目与设计文档目录

本目录存放跨阶段、需要持续维护的正式项目文档。

计划产出：

- `ai-coding-workflow.md`：个人 AI 编程流程。
- `rag-design.md`：解析、切片、索引、检索和引用设计。
- `tool-security.md`：Java Tool Calling 权限边界。
- `spring-ai-vs-langchain.md`：框架实测对比。
- `langgraph-workflow.md`：状态、节点、路由和审批。
- `claude-agent-security.md`：Claude Agent 权限、Hooks 和隔离。
- `architecture.md`：首个端到端 AI 应用架构。
- `evaluation.md`：评测方法与结果。
- `security.md`：整体威胁模型和残余风险。
- `platform-architecture.md`：控制面、执行面、数据面和信任边界。
- `platform-domain-model.md`：Project、Agent、Version、Tool、Workflow、Run 和 Eval 模型。
- `model-gateway.md`：模型适配、路由、配额、Fallback 和成本策略。
- `workflow-runtime.md`：工作流 DSL、状态机、Checkpoint、幂等和恢复。
- `platform-governance.md`：RBAC、审批、审计、发布门禁和版本治理。
- `production-readiness.md`：SLO、容量、告警、备份、恢复和发布评审。

业务调研、AS-IS/TO-BE 和试点材料放入 `business-cases/`，不要混入纯技术架构文档。文档必须反映当前实现。实验性的短期笔记放入 `notes/`，每周成果索引放入 `deliverables/`。
