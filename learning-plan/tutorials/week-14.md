# 第 14 周教程：Java/Python 组合

> 计划来源：[05-integration-evaluation-delivery.md](../stages/05-integration-evaluation-delivery.md)。阶段文档决定课程任务和验收，本文件解释逐节学习方法；学习状态仍只记录在[第 14 周成果](../../deliverables/week-14/README.md)。

## 本周先理解

### 为什么学

把控制面与执行面通过稳定协议组合起来，验证超时、取消和部分失败不会形成假成功。

### 这是什么

组合架构用 Java 承担平台 API 与治理，用 Python 承担 Agent 工作流和开放式执行，两端通过版本化 Schema 协作。

### 本周语言定位

同时使用 Java 控制/API 层与 Python Agent 执行层；两端通过版本化 Schema、稳定错误、traceId、超时和取消语义连接。完整职责、切换桥接和替代规则见[开发语言路线](../01-language-roadmap.md)。

### 本周学习策略

- 每天只完成下面一节，控制在约 1 小时，不提前堆叠下一节的新概念。
- 先预测再实验；先保存原始证据，再写结论；失败样例与正常结果同等重要。
- 首次遇到术语时补齐：一句话定义、输入输出、开发类比、类比边界、反例和“不是什么”。
- 使用 H1→H4 提示阶梯；若使用完整参考答案，必须额外完成一个不同输入或约束的变体。

**这个是什么**

本周核心概念是：组合架构用 Java 承担平台 API 与治理，用 Python 承担 Agent 工作流和开放式执行，两端通过版本化 Schema 协作。今天的“定义 Java/Python API 协议”是这个核心能力的最小学习单元：你会通过“先写 JSON 示例和错误状态，再生成两端模型；协议包含版本、任务 ID 和幂等标识”观察输入如何转化为“字段、错误码和状态一致”。它既包含可观察结果，也包含至少一个失败或不适用边界。只读完资料或只跑通正常路径，都不能证明已经掌握。

**怎么学（约 60 分钟）**

1. `0–5 分钟`：不查资料，写下你对本节主题的一句话解释、预期输入输出和一个疑问。

3. `15–45 分钟`：执行专项任务：先写 JSON 示例和错误状态，再生成两端模型；协议包含版本、任务 ID 和幂等标识
4. `45–55 分钟`：主动制造一个错误输入、边界条件、依赖失败或反例，保存现象并解释原因。
5. `55–60 分钟`：整理命令、输入、输出、Diff、图表或访谈证据，并用自己的语言完成 Teach-back。

专项资料：[OpenAPI Specification](https://spec.openapis.org/oas/latest.html)

**怎么验证学会了**

- 必交证据：字段、错误码和状态一致。
- Teach-back：不看资料解释“定义 Java/Python API 协议”解决什么问题、主要输入输出、一个边界，以及它不是什么。
- 失败证据：展示一个非正常场景，指出失败发生在哪一层，不能只贴错误截图。
