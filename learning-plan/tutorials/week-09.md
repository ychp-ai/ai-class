学习模型、消息、结构化输出和工具抽象，并能与手写 Agent 比较新增状态与失败模式。

```python
from langchain.agents import create_agent
from langchain.tools import tool

@tool
def lookup(query: str) -> str:

    if not query.strip():

print(result)
```
