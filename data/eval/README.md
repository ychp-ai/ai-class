# 评测数据目录

本目录存放第 15 周使用的固定 RAG 和 Agent 评测集。

建议结构：

```text
data/eval/
├── rag-cases.jsonl          # 问题、预期答案、预期来源、评分规则
├── agent-cases.jsonl        # 任务、初始状态、允许副作用、验收命令
├── baseline/                # 可提交的汇总结果和脱敏样例
└── generated/               # 本地完整运行输出，默认不提交
```

优化前先固定数据集和评分规则。必须保留失败案例，但日志中的 Prompt、工具参数和模型输出需要脱敏。
