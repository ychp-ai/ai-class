# 第 40 周公共成果要求：对照评测与独立交付

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/11-super-agent-reliability.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-40.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- 两个方案的不可变发布清单，相同模型、数据、工具、权限、总预算、到达顺序与环境。
- 30 条固定场景至少三轮逐例结果；开发/留出、Fake/真实模型分开记录，失败不得删除。
- 质量、耗时、总成本、人工介入、通知量及样本量可复算；安全和确定性控制断言全部通过。
- 独立约束变体的需求、取舍、实现、陌生故障排错与迁移证据，附提示级别及个人贡献。
- 复现入口、24 小时报告、运行手册、限制与推广/调整/停止决策；主线毕业、专项学习结论与生产决策分开。

## 独立掌握验证

讲师现场改变渠道、权限或故障位置；学习者独立设计、实现关键路径、排错并复述边界。

## 个人记录要求

在个人仓库的 `deliverables/week-40/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
