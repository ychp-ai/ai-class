# 第 33 周公共成果要求：需求、独立设计与单会话基线

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/10-super-agent-coordination.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-33.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- 原九阶段及第 32 周双验收引用，阶段前测与补救结果。
- 受限场景需求、允许动作、人工接管点及至少两种架构取舍。
- Task/Run、revision、release、身份、截止时间与授权引用的契约；非法建议/缺身份被拒绝。
- 30 条固定案例清单：20 条开发输入与 10 条讲师保管的留出索引；模型条件、顺序、阈值和评分冻结。
- 三个代表任务的单会话实跑基线，真实与 Fake 明确区分；总成本包含失败与重试。

## 独立掌握验证

关闭 ADR 后解释路由与权限边界；把一个 Agent 任务改成普通函数方案，说明选择依据。

## 个人记录要求

在个人仓库的 `deliverables/week-33/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
