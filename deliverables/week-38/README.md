# 第 38 周公共成果要求：多任务持久恢复与副作用核对

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/11-super-agent-reliability.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-38.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- Task/Run、事件/命令与 Checkpoint 的持久归属图和恢复入口。
- Outbox 与状态同事务，重复派发仍需接收端幂等；旧 epoch Worker 无法写入。
- 未知外部写先查询/核对；不支持查询或幂等时停下交人工。
- 实际进程在入库后、派发后、外部成功未本地确认三处退出，再恢复三个任务。
- 持久外部 Stub 保留账本，已完成动作计数为 1；审批与当前权限在恢复时仍生效。

## 独立掌握验证

讲师更换退出位置，学习者不改库独立定位，给出安全恢复或停止决策。

## 个人记录要求

在个人仓库的 `deliverables/week-38/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
