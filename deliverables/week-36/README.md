# 第 36 周公共成果要求：跨渠道身份与上下文

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/10-super-agent-coordination.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-36.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- 两种本地协议适配器，同一授权用户补充可关联同一 Task。
- 可信身份绑定与可撤销关联；同名异人、跨 Project、歧义消息不得自动串任务。
- 消息来源与任务关系可追溯，冲突补充交人工，修改留审计。
- 任务工作记忆按主体/Project 隔离，权限变化后不能返回旧的无权内容。
- 阶段十独立考试：只给目标/资源/成功条件，完成边界、方案选择、最小变体与陌生失败解释。

## 独立掌握验证

关闭课程范例，独立处理一种新入口或新的身份冲突；记录提示级别，不以已有完整实现代替考试。

## 个人记录要求

在个人仓库的 `deliverables/week-36/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
