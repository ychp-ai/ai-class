# 第 39 周公共成果要求：持续运行与运维

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/11-super-agent-reliability.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-39.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- 存活与有效进展分别观测，等待审批不会被误当成无进展故障。
- Watchdog 有截止时间、重试上限、人工接管和去重通知。
- 队列、命令接收/生效、恢复、资源、成本指标与发布版本关联。
- 停止接纳、在途核对、重启与版本回滚记录，已有业务事实不会随版本回退消失。
- 连续至少 24 小时受控墙钟运行报告：定时事件、重启/停滞注入、资源曲线、成本封顶和终止开关；加速测试另列。

## 独立掌握验证

另一操作者按 Runbook 处理停滞并终止/恢复；说明何时重试，何时必须人工核对。

## 个人记录要求

在个人仓库的 `deliverables/week-39/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
