# 第 35 周公共成果要求：事件接入与主动触发

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/10-super-agent-coordination.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-35.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- 来源、eventId、actor、project、时间与 payloadRef 的事件信封及来源校验。
- 持久 Inbox 与去重约束；重复、乱序、重启重投不会重复开工或倒退终态。
- 主动规则与授权版本，观察/忽略/待人工/可执行状态区分，不能由聊天正文授予权限。
- 订阅失效、来源突发与背压行为；未接纳事件可查询并能补投。
- 完成、阻塞、需决策的低噪声通知证据，通知目标与租户归属校验。

## 独立掌握验证

改变事件到达顺序与授权规则，解释主动触发为什么仍受权限、预算和人工责任约束。

## 个人记录要求

在个人仓库的 `deliverables/week-35/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
