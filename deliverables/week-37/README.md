# 第 37 周公共成果要求：中途纠正、取消与撤权

本目录接收课程计划与统一门禁，输出可供个人仓库引用的验收清单。只保存公共要求；禁止填写个人状态、评分、运行日志、真实凭证或唯一成果副本。

计划来源：[阶段计划](../../learning-plan/stages/11-super-agent-reliability.md)；学习步骤：[本周教程](../../learning-plan/tutorials/week-37.md)。本周属于原 32 周毕业后的强化范围。

## 必交证据

- 持久命令收件箱，接收与生效独立记录，重复/越权命令被拒绝。
- 慢工具期间控制通路与另外两个任务可推进，接收延迟有证据。
- revision 安全生效，旧结果不能覆盖新目标，发布快照仍不可变。
- 取消先到、结果先到、结果迟到的终态断言与已发生动作凭证。
- 暂停后撤权再恢复被阻断；在途外部动作进入核对，后续新动作禁止。

## 独立掌握验证

把取消改成缩小范围，独立说明命令接收、生效、撤权和补偿之间的区别。

## 个人记录要求

在个人仓库的 `deliverables/week-37/README.md` 链接真实成果，填写实际命令、版本、输入输出、退出状态、失败定位、关键取舍和未验证范围。设计写 `docs/`，实现写对应语言目录，数据写 `data/`，隔离任务写 `sandbox-workspaces/`，不把唯一成果复制进课程仓库。

讲师按[统一规范](../../learning-plan/07-instructor-supervision.md)给出“通过、部分通过、未通过”，记录掌握度、Teach-back、变体、学习债务和下次复习；只运行示例最高为 L1。公共模板的存在不代表学习通过。

## 验收与后续输入

本周证据须满足[专项门禁](../../learning-plan/11-super-agent-reinforcement.md#固定评测集与专项门禁)和[成果标准](../../learning-plan/06-deliverable-standards.md#super-agent-强化成果索引)。未通过先补救，列出下一步可依赖的接口、数据、版本和待验证项；未运行的实验不能填入已通过结果。
