# AI 学习计划：程序员从入门到实践

这是一份面向程序员的 AI 学习计划，按照每天 1 小时设计，从基础工具使用逐步过渡到 AI 应用开发、RAG、工具调用、Agent 和评估体系。

## 学习目标

完成这份计划后，你应该能够：

- 熟练使用 AI 工具辅助日常开发
- 掌握 Prompt 编写和 AI 代码审查方法
- 使用 AI 辅助理解代码库、修复 bug、补充测试和重构
- 调用大模型 API 构建基础 AI 应用
- 理解并实现 RAG、工具调用和简单 Agent
- 为 AI 应用建立基础评估和复盘机制
- 完成一个可展示的 AI 综合项目

## 每日节奏

每天学习 1 小时，建议固定为：

- 15 分钟：学习一个概念
- 35 分钟：动手练习
- 10 分钟：复盘记录

每天复盘模板：

```text
今天学了：
今天做了：
AI 帮我节省了什么：
AI 犯了什么错：
我沉淀的 Prompt：
明天要继续：
```

## 第 1-2 周：AI 工具入门

## 学习原则

- 每天都要有一个小产出
- 让 AI 先解释、再生成、最后由人审查
- 不盲信 AI 代码，必须看 diff、跑测试、查边界
- 把好用的 Prompt 和踩坑记录沉淀下来
- 学习重点放在工程实践，而不是一开始钻进模型训练细节
