# Prompt 目录

本目录存放经过验证、可以重复使用的 Prompt，而不是临时聊天内容。

建议按周或场景组织：

- `week-03.md`：Prompt 基础、版本和固定回归练习。
- `coding.md`：需求拆解、实现、测试和代码审查。
- `rag.md`：检索问答、引用和拒答。
- `agent.md`：任务规划、权限和验收要求。

每个 Prompt 应说明用途、所需输入、约束、期望输出、版本、关联 Eval 数据集和至少一个验证记录。已发布 Agent 引用不可变 Prompt 版本，不能直接覆盖线上内容。不得包含真实 API Key、Cookie、Token 或敏感业务数据。
