# AGENTS.md

本仓库是个人学习与成果仓库。课程目标、教学规则、技术路线和成果门禁以配套 `ai-class` 课程仓库的 `AGENTS.md` 与 `learning-plan/` 为准。

## 配套课程仓库

- Git 仓库：`git@github.com:ychp-ai/ai-class.git`
- 默认本地目录：`../ai-class`
- 规则文件：`../ai-class/AGENTS.md`
- 学习路线：`../ai-class/learning-plan/README.md`

课程仓库是课程内容和规则的唯一来源；本仓库是个人进度与成果的唯一来源。两边内容不得混写。

- 个人进度、笔记、验收记录或成果发生变更时，完成必要检查后直接使用 Conventional Commit 提交并推送，无需再次确认。
- 该持续授权仅适用于当前个人仓库的正常学习记录，不授权创建或删除分支、改写历史、强制推送或操作其他仓库。
- 个人状态、周笔记、验收记录和成果只写入本仓库，不修改课程仓库中的课程模板。
- `deliverables/week-XX/README.md` 是当周状态的唯一入口，`notes/week-XX.md` 记录学习过程。
- 源码、文档、数据和业务案例按根 README 的目录边界存放，并从周成果记录链接。
- 不得提交真实 Secret、个人敏感信息、客户数据、生产导出或未脱敏日志。
- 不得仅凭文件存在、Commit 数或自然日期推进进度；必须保留运行、失败、Teach-back、变体和讲师验收证据。
