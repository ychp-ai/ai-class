# 学习者仓库模板目录

本目录保存从课程仓库复制到个人学习仓库的公共文档模板。模板只定义目录、字段和安全边界，不包含任何学习者姓名、当前周、完成状态、评分或个人成果。

- `learner-repository/`：个人仓库的完整文档骨架，包括根文档、周进度、周笔记、技术实现、数据、业务案例、基础设施、Prompt 和沙箱目录说明。
- 个人仓库需要的所有模板统一在该目录维护；课程根目录不再保留同名模板目录。
- `scripts/init_learning_progress.py` 是标准复制入口；模板占位符由脚本渲染。

```bash
python3 scripts/init_learning_progress.py \
  --course-repo . \
  --progress-repo ../ai-class-note
```

该命令只创建个人仓库中尚不存在的文件，因此可以在初始化后再次执行，不会覆盖学习者已经填写的进度或笔记。

禁止在本目录保存个人学习记录、真实密钥、运行日志、业务数据或唯一成果副本。
